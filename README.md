# Arpit Tak — Portfolio

Personal portfolio and software engineering showcase. Built with clean semantic HTML5, modern CSS, and vanilla JavaScript with zero runtime dependencies.

## Overview

- **Design**: Minimalist editorial aesthetic with warm graphite & paper palettes, electric blue accents, and subtle tactile dot grid background.
- **Theme Switch**: Segmented dual-icon sliding switch with system preference detection and keyboard shortcut (`D`).
- **Interactions**: One-click confidential email copy with instant feedback, live Bengaluru timezone clock (IST).
- **Projects**:
  - **Outpost**: Real-time collaborative agentic workspace with live canvas and document sync ([Live Demo](https://outpost-arpit.netlify.app) · [Code](https://github.com/arpittak027/OUTPOST))
  - **Bolo India**: Voice-first computing platform for Indian multilingual workflows ([Code](https://github.com/arpittak027/bolo-india))
  - **QuickEMS**: Full-stack employee management system with role-based auth ([Live Demo](https://polite-llama-edf38a.netlify.app/login) · [Code](https://github.com/arpittak027/quickems))

## Stack

- **Markup**: Semantic HTML5
- **Styling**: Vanilla CSS3 (Custom properties, responsive grid & flexbox)
- **Scripting**: Vanilla ES6+ JavaScript (0 dependencies)
- **Typography**: Newsreader (Serif), Inter (Sans), JetBrains Mono (Monospace)
